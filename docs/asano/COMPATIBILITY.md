# ASANO 32LH7030S — адаптация API 24

Дата: 2026-11-09. Ветка: `feature/android7-asano`.
База: `Gathin23/cleanyourtv@294d3d59dc2514e69fed557f46c1ecdfb87a95ec`.

**Статус: подготовлены исходники; компиляция и Android Lint не выполнены. APK отсутствует. Совместимость на телевизоре не подтверждена.**

## Сделанные изменения

| Место | Изменение и основание |
|---|---|
| `launcher/app/build.gradle` | `minSdk 24`, собственный ID `com.killupdate.cleanmytv`, версия `0.1.0-asano-api24-audit`. Release больше не подписывается общедоступным debug-ключом. |
| Java time | Включён core library desugaring; явно объявлена версия `com.android.tools:desugar_jdk_libs:2.0.4`. Библиотека не скачана и её содержимое не проверено. |
| `MainActivity` | `getChangedPackages` вызывается только на API 26+. На API 24 сравнивается упорядоченный список имён, версий, времени обновления и enabled-состояний пакетов. Это обнаруживает замену приложения при прежнем количестве пакетов. Существующие package broadcasts сохранены. |
| `UiFont`, `values/fonts.xml`, `values-v26/fonts.xml` | `Resources.getFont` защищён проверкой API. На Android 7 используются системные sans-serif семейства; на API 26+ сохранены оригинальные встроенные шрифты. Начертания Android 7 могут отличаться. |
| `WallpaperCaptions` | `File.toPath` / `Files.readAllLines` заменены на `BufferedReader` и `FileInputStream`, совместимые с API 24. |
| `WallpaperPlayer` | `Bitmap.Config.HARDWARE` применяется только на API 26+; Android 7 оставляет программный bitmap. |
| HDMI | Добавлен проверяемый CVTE-маршрут: только зарегистрированный вход, существующая экспортированная системная `com.cvte.tv.androidsetting.TvSettingActivity`, целочисленный `MTK_EXTRA_INPUT_ID`, извлечённый из `/HWn`. Соответствия HDMI-портов не угаданы и не зашиты. При отказе запуска сохраняется исходный стандартный путь. |
| ТВ и настройки | По локальному списку системных пакетов выбраны `com.cvte.tv.player` и резервный обработчик `com.cvte.tv.androidsetting`. Наличие пакетов известно из резервной копии, работоспособность их точек входа не проверена. |
| Возврат | В меню добавлен «Штатный экран ASANO». Последний запасной адрес — предоставленная владельцем `com.asd.launcher/com.asd.launcher2.Launcher2_2`. Это запуск интерфейса, а не изменение Home по умолчанию. |
| Сеть | Убраны сетевые наблюдатели, SSID/VPN-индикация и все uses-permission исходного Manifest. Кнопка Wi-Fi открывает системные настройки. Задержка открытия приложения, если настроена, стала фиксированной локальной задержкой. |
| Темы | Парсер и UI тем/обоев сохранены, но их каталог переведён в приватное хранилище. Прежняя загрузка тем через внешнее Android/data и ThemeProvider больше не работает; безопасный импорт локальных наборов требует отдельной реализации/проверки. Параметры локальных ресурсов в исходниках остаются доступны для подготовки сборки. |

Основной источник опыта: [issue #1664](https://github.com/Gathin23/cleanyourtv/issues/1664) и уже находившаяся в зафиксированном снимке [заметка Mtek](../devices/mtek-mk32cs1nb.md). Там испытан **другой** телевизор и более ранняя версия лаунчера; его результаты не являются тестом ASANO.

[Официальная документация Android по desugaring](https://developer.android.com/studio/write/java8-support) подтверждает подход к переносу java.time. Это не заменяет проверку конкретного DEX и lintRelease.

## Что сохранено и что пока не доказано

Сохранены исходные Activity, RecyclerView-сетка, избранное, перестановка плиток, настройки, запуск сторонних приложений, D-pad/OK/Back обработчики, стандартный HOME intent filter и основной интерфейс. Исключены глобальные accessibility-перехватчики Home/Input и восстановление привилегированных служб. Обычная навигация внутри приложения не зависит от этих служб; обработка аппаратного Home и SOURCE вне приложения зависит от прошивки и выбранного пользователем Home.

В исходниках лаунчера нет `.so`, NDK или ABI-фильтра. Ожидается Java/DEX-сборка для ARMv7, однако отсутствие native-библиотек **в будущем APK** ещё не проверено. Экран 1366×768, реальные HDMI, канал ТВ, пульт, сон/пробуждение и расход памяти не испытывались.

## Препятствия

На Mac не найдены рабочие JDK, Gradle, Android SDK и кэш зависимостей. Скачивание среды было отклонено автоматической проверкой разрешений из-за запрета загрузчиков в правилах проекта; затем владелец явно выбрал «Только аудит и правки, без скачивания». Поэтому инструменты Android и зависимости не скачивались, сборка не запускалась.

Для следующего разрешённого этапа необходимы проверенная среда JDK 17 / Gradle 8.9 / SDK 34, проверенные AndroidX и desugaring с транзитивными зависимостями, затем offline unit tests, lintRelease (включая NewApi), release build, merged Manifest/DEX/ABI/signature проверки. Для выпуска необходим отдельный приватный ключ владельца; его нельзя включать в Git.
