# Пробная установка и возврат — план на будущее

**Сейчас APK отсутствует. Ничего не устанавливать. Этот документ не является разрешением на действия с телевизором.**

## Условия допуска

Нужны отдельное разрешение владельца, успешная сборка/Android Lint, проверка merged Manifest (minSdk 24, отсутствие сетевых и ненужных разрешений), DEX/native-библиотек, подписи и SHA-256. Зафиксировать сертификат и хранить приватный ключ отдельно от Git. APK брать только из собственного проверенного релиза; чужой готовый файл не подходит.

## После допуска

1. Сохранить резервную информацию о штатном Home и убедиться, что `com.asd.launcher` включён. HOME Activity из предоставленных владельцем сведений: `com.asd.launcher/com.asd.launcher2.Launcher2_2`. Не запускать заводские/test-Activity.
2. На отдельном согласованном этапе установить APK обычным способом, не предоставляя root, WRITE_SECURE_SETTINGS, accessibility или доступ к уведомлениям. Не использовать старые build-and-install, disable, restore или debloat-скрипты.
3. Сначала открыть CleanMyTV из списка приложений штатного интерфейса. Не назначать его постоянным Home. Проверить D-pad, OK, Back, запуск/возврат из приложений, сетку, избранное, перестановку, доступ к настройкам и пункт «Штатный экран ASANO».
4. Проверить реальные HDMI и эфирные каналы через штатные компоненты, затем сон/пробуждение. SOURCE вне экрана штатного TV-приложения может обрабатываться прошивкой иначе; это не исправлять отключением сервисов.
5. Если появится выбор Home, для первой проверки выбрать вариант однократного запуска. Постоянный Home менять только после отдельного согласования и подтверждённого возврата к штатному экрану.
6. При сбое остановиться и сохранить описание/логи без публикации адресов, серийных номеров и аккаунтов. Не отключать системные компоненты, не менять прошивку и не запускать команды «исправления» вслепую.

## Возврат

Пункт «Штатный экран ASANO» открывает исходный лаунчер без изменения его состояния. Через системные настройки приложений/Home выбрать штатный интерфейс либо сбросить только выбор нового Home. Если приложение не запускается, использовать штатные настройки с пульта. Удалять пробное приложение через обычные настройки допустимо только на отдельно согласованном этапе; системные приложения не трогать.

Если штатный экран не удаётся открыть, остановиться: не применять factory reset, root или отключение пакетов. Поскольку штатный лаунчер в этом плане остаётся включённым, его отключение не является частью восстановления.

Во время текущей работы ни установка, ни изменение Home, ни другие команды на телевизоре не выполнялись.
