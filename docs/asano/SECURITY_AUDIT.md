# CleanMyTV — ограниченный аудит исходников

> Исторический отчёт об адаптации исходников. Состояние после сборки и проверки подписанного тестового APK описано в [APK_AUDIT.md](APK_AUDIT.md).

Дата: 2026-11-09. Статус: **аудит исходного кода частично завершён; аудит зависимостей и APK заблокирован. Релиз не разрешён результатами этой проверки.**

## Область и методы

Основа — неизменный исходный commit `294d3d59dc2514e69fed557f46c1ecdfb87a95ec`; новые версии оригинала не загружались. Проверены объявления сборки лаунчера, исходный Manifest, XML ресурсов и ключевые пути приложения: запуск, обнаружение пакетов, HDMI, настройки, конфигурация, шрифты/обои, module cards, accessibility repair и guard-механизмы. Все 75 Java-файлов основного лаунчера учтены по SHA-256; 8 исключены из sourceSet, 67 включены в статический поиск.

Методы: локальный поиск опасных API, ручное чтение критических участков, XML parsing, проверка правил исходного Manifest, фиксация зависимостей, сравнение wrapper-хэшей, `git diff --check`. Скрипт `tools/audit_asano_source.py` использует только стандартную библиотеку Python, не импортирует проект, не выполняет его код и не обращается в сеть или к ТВ. Машинный результат: [SOURCE_CHECKS.json](SOURCE_CHECKS.json).

Это не полный ручной построчный анализ всех 15 тысяч строк, не антивирусное заключение и не доказательство отсутствия неизвестных уязвимостей. Код на телевизоре не запускался, сетевой трафик процесса не наблюдался.

## Результаты и исправления

| Наблюдение | Действие / статус |

## Разрешения и проверка APK

**Исходный Manifest:** 0 запрашиваемых разрешений. BIND_DREAM_SERVICE на service — ограничение того, кто может привязаться к нему, а не запрашиваемое разрешение приложения.

**Merged Manifest / APK / DEX / сертификат / SHA-256 APK:** отсутствуют, потому что APK не собран. Зависимости могут добавить manifest-элементы: проверка исходного XML не заменяет проверку итогового файла. Проверка на устройстве или эмуляторе не выполнялась. Сервисам анализа исходники/APK не отправлялись.

## Оставшиеся риски

1. Изменения ещё не компилировались, Android Lint/NewApi и unit tests не выполнены.
2. AndroidX/desugaring, транзитивные зависимости и итоговые артефакты не проверены.
3. CVTE Activity, реальные номера/идентификаторы входов, эфирные каналы и кнопки Home/SOURCE на ASANO не подтверждены; другой MT5863-телевизор из issue #1664 — лишь основание для адаптации.
4. Приватный каталог защищает конфигурацию, но прежний внешний импорт тем недоступен. Для сохранения полного сценария локальных тем нужен отдельный безопасный импорт.
5. Шрифты Android 7 отличаются от исходных переменных шрифтов. Экран 1366×768 и память ARMv7 не испытаны.
6. Старые tools/add-ons могут выполнять административные и сетевые действия, если вручную запустить их вне согласованного процесса. Они не входят в launcher APK и не должны использоваться для ASANO без отдельного аудита.
7. Android 7 и прошивка 2019 года сами имеют риски, которые лаунчер не исправляет. Оценка прошивки не входила в эту работу.

Ни один системный пакет не менялся, штатный `com.asd.launcher` не отключался. Ветку нельзя называть «проверенный APK» или выпускать как безопасный релиз до закрытия перечисленных проверок.
